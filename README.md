# Sony Xperia 8 proprietary files

Generated vendor configuration and proprietary components for Himiko on
LineageOS 23.2. Place this repository at `vendor/sony/himiko`.

The matching device repository contains `proprietary-files.txt` and
`extract-files.py`, which record the source hashes and extraction fixups. The
baseline is Sony 56.1.C.3.231, customization 1320-4144/R6C. Selected component
replacements and their pinned hashes are documented in that extraction list.

Individual proprietary components retain their original ownership and terms.
The generated files must remain synchronized with the matching device tree.

This directory previously had no independent Git repository. Its history was
reconstructed from preserved vendor checkpoints; these commits record saved file
contents rather than original historical Git commits. Intermediate changes absent
from those checkpoints cannot be recovered.
